# Preguntas frecuentes sobre rendición de gastos de Consultora Andes Ficticia

Versión 1.0 | Vigente desde el 2026-03-01 | Documento SINTÉTICO escrito para este proyecto académico. Complementa la política de rendición v2 y la guía de categorías v1.

## 1. ¿Qué hago si perdí la boleta?

Una boleta perdida no se puede reembolsar. Si el comercio puede emitir un duplicado con la misma fecha y el mismo monto, se rinde con el duplicado. No se aceptan estimaciones ni declaraciones propias en lugar del comprobante.

## 2. ¿Puedo rendir un gasto de un compañero?

Cada persona rinde solo lo que pagó con su propio dinero. Si pagaste por un compañero, rindes tu parte y él rinde la suya, siempre que el comprobante permita separar los montos.

## 3. ¿Qué pasa si el monto supera el límite de la categoría?

Se reembolsa hasta el límite y el resto lo asume quien gastó. No se puede dividir una misma compra en varias boletas para esquivar el límite.

## 4. ¿Cuándo se paga el reembolso?

El reembolso se paga con el cierre contable del mes, que es el día 25. Lo aprobado antes del cierre se paga ese mes, y lo aprobado después se paga con el cierre del mes siguiente.

## 5. ¿Qué hago si el comprobante está borroso?

Si la foto no permite leer la fecha, el comercio o el monto total, no se acepta. Se debe tomar una nueva foto con buena luz y el comprobante completo, sin dobleces.
